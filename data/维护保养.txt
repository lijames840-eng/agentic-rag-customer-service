文档用途：智扫通Agent 知识库 · 保养指导与耗材管理
品牌对象：智扫（Zhisao）S1 / S2 / S3 Pro / X1

使用说明：按"周期 + 部件"双维度组织，可按周期检索，也可按部件检索。含耗材更换周期表与保养记录模板。


=== 一、保养总览：一张表看懂什么时候做什么 ===

【日常（每次任务后）】
1. 倒空尘盒（自动集尘机型检查尘袋余量）。
2. 拖地任务后清空污水箱、补满清水箱（自清洁基站机型）。
3. 检查地面是否有缠绕物被卷入。
4. 确认机器人已回充。

【每周】
1. 清理主刷缠绕的毛发（重点：两端轴承）。
2. 清理边刷刷毛上的头发、灰尘。
3. 取出滤网，轻拍除尘（不要水洗，水洗按滤网保养周期）。
4. 擦拭机身前挡板、激光塔外壳（干布或微湿布）。
5. 检查驱动轮、万向轮是否缠毛。
6. 自清洁基站机型：拆洗清洗盘，擦干基站内壁。

【每月】
1. 滤网水洗一次（彻底晾干24小时）或直接更换。
2. 擦拭悬崖传感器、沿墙传感器、回充极片。
3. 清洁基站集尘仓、检查尘袋。
4. 检查边刷是否卷边、变形（需要则换）。
5. 检查拖布磨损情况（变薄、掉毛、变硬则换）。
6. 用微湿布擦拭机身底部与轮组。

【每季度（约3个月）】
1. 更换边刷（一对）。
2. 更换拖布（一对）或深度清洗+消毒。
3. 深度清洁基站：拆清洗盘、冲洗排水孔、擦净水箱内壁。
4. 检查主刷刷毛长度，明显变短则更换。
5. 检查电池续航，记录满电可清扫面积（对比新机）。
6. 清理水箱水垢（白醋浸泡30分钟）。

【每半年（约6个月）】
1. 更换主刷（养宠/长发家庭3—6个月）。
2. 更换滤网（2个月一换，此处为强制节点）。
3. 检查驱动轮、万向轮磨损与旋转顺畅度。
4. 检查电源线、适配器是否有破损、发烫。
5. 全面清洁风道（可用长柄软刷）。

【每年】
1. 评估电池健康度（续航低于标称50%考虑更换）。
2. 更换尘袋若干（按45—60天周期，实际约6—8个/年）。
3. 检查基站水泵、加热模块工作状态（洗拖布水温、烘干热风）。
4. 检查上下水模块管路（如有）、清洗进水滤网。
5. 固件更新到最新稳定版本。

【每2—3年】
1. 更换电池（S1/S2 199元，S3 Pro/X1 299元）。
2. 更换基站清洗盘（如变形、密封老化）。
3. 评估整机是否换代（避障、自清洁已有代际提升时）。


=== 二、核心部件保养详解 ===

【主刷（滚刷/胶刷）】
清洁频率：每周一次；深度清理每月一次。
操作步骤：
1. 关闭电源，翻转机器，按下卡扣取出主刷。
2. 用清理刀（机身自带或随机附件）沿刷体凹槽割断缠绕毛发。
3. 重点清理刷体两端的轴承/端盖（毛发最易堆积处）。
4. 用干布擦拭刷体，检查刷毛是否整齐、有无缺口。
5. 手动转动刷体，确认顺畅无卡顿后装回，听到"咔"声即到位。
注意事项：
- 不要用剪刀尖硬撬轴承，会损伤密封。
- 不要水洗带电机端的主刷（部分机型主刷可整体水洗，需确认说明书）。
- 胶刷出现裂纹、缺口立即更换。
更换周期：6—12个月（养宠家庭3—6个月）。

【边刷】
清洁频率：每周。
操作步骤：
1. 拔下边刷（多数为直接上拔或按压卡扣）。
2. 清除刷毛间的毛发，可用梳子或手指反向梳理。
3. 检查刷毛是否卷边：卷边可用80℃热水浸泡3分钟，理直后压平冷却。
4. 装回时对准卡槽按压到位。
注意事项：
- 边刷是易损件，卷边后清扫半径变小，墙边会漏扫。
- 不建议用非原装边刷（硬度不当会刮花地板）。
更换周期：2—3个月。

【HEPA滤网】
清洁频率：每周轻拍除尘；每月水洗一次。
操作步骤：
1. 打开尘盒上盖，取出滤网组件（滤网+支架）。
2. 轻拍或用软毛刷去除表面浮灰（不要用力搓）。
3. 水洗时用清水从滤网背面（干净面）冲洗，水流不要过急。
4. 甩掉多余水分，平放在通风处阴干24小时（严禁暴晒、吹风机热风）。
5. 完全干燥后装回，确认边缘密封到位。
注意事项：
- 未干透装回会导致：异味、霉菌、吸力下降、风机受损。
- 水洗超过5次或2个月，过滤效率明显下降，建议更换。
- 出现破损、变形、边缘脱胶立即更换。
更换周期：2个月（或水洗5次）。

【尘盒】
清洁频率：每次任务后倒空；每月深度清洗。
操作步骤：
1. 按下尘盒释放键取出尘盒。
2. 打开上盖倒出垃圾（对着垃圾桶轻磕）。
3. 每月用清水冲洗尘盒内部，软刷清理角落积灰。
4. 检查密封圈是否变形、脱落，擦干后装回。
注意事项：
- 尘盒必须完全晾干再装（潮湿会导致垃圾结块、异味）。
- 密封圈老化会导致吸力下降、灰尘从缝隙漏出。
- 不要用酒精、84消毒液擦拭（腐蚀塑料件）。

【尘袋（自动集尘机型）】
更换频率：45—60天（按每天1次、100㎡估算）。
操作步骤：
1. 打开基站上盖，握住尘袋提手向上抽出。
2. 尘袋自带密封挡片会自动闭合（避免扬尘）。
3. 装入新尘袋，将袋口纸板完全卡入卡槽（听到"咔"声）。
4. APP中"耗材管理—尘袋"重置计时。
注意事项：
- 不要等完全装满再换（会降低集尘吸力、可能倒吸）。
- 不要重复使用尘袋（密封片一次性）。
- 尘袋受潮（梅雨季）需缩短更换周期。

【拖布（旋转/平板）】
清洁频率：每次拖地后（基站自动洗）或手洗；每2周深度清洗。
操作步骤：
1. 拆下拖布（撕开魔术贴或按下卡扣）。
2. 温水+少量中性洗衣液搓洗，顽固污渍用氧净浸泡30分钟。
3. 清水漂净，挤干水分。
4. 基站烘干或通风晾干（避免阳光直晒，纤维会老化）。
5. 装回时确认贴合平整、无褶皱（褶皱会留痕）。
注意事项：
- 禁止使用柔顺剂（破坏纤维吸水性）。
- 变硬、掉毛、变薄立即更换。
- 厨房、卫生间拖布建议与卧室分开使用。
更换周期：2—3个月。

【水箱（清水箱/污水箱）】
清洁频率：每次任务后倒污水；每周冲洗；每月除垢。
操作步骤：
1. 取出水箱，倒空残水。
2. 清水冲洗内壁，软布擦拭（不要用硬刷）。
3. 每月用1:10白醋水浸泡30分钟除垢，再清水冲净。
4. 开盖晾干后装回（长期潮湿会发霉）。
注意事项：
- 不要用热水（超过60℃会变形）。
- 密封圈老化会漏水，可单独更换（约15元）。
- 长期不用必须清空晾干。

【基站清洗盘】
清洁频率：每1—2周。
操作步骤：
1. 断电（拔掉基站电源更安全）。
2. 抽出清洗盘（多数为整体可抽出）。
3. 温水冲洗，软刷刷掉毛发和污垢。
4. 重点疏通排水孔（毛发堵塞会导致积水、异味）。
5. 擦干后装回，确认卡到位。
注意事项：
- 清洗盘积垢是"拖布反复发臭"的首要原因。
- 每1个月可用稀释消毒液浸泡10分钟。
- 盘体变形、密封条老化需更换（1—2年）。

【传感器（悬崖/沿墙/回充/地毯识别）】
清洁频率：每月（环境灰尘大时每2周）。
位置：
- 悬崖传感器：机身底部前侧4—6个黑色半透明小窗。
- 沿墙传感器：机身侧面（右侧常见）透明窗。
- 回充信号窗：机身正面/基站正面。
- 地毯识别：机身底部前侧（超声波窗口）。
操作步骤：
1. 断电，用干燥软布或棉签擦拭窗口。
2. 顽固污渍用微湿布轻擦后立即擦干。
3. 禁止使用酒精、溶剂（会腐蚀透明罩，导致误判）。
注意事项：
- 传感器脏污是"悬崖误报""不贴边""回充失败"的常见原因。
- 透明罩划伤会影响精度，需更换。

【激光塔（LDS/dToF）】
清洁频率：每月。
操作步骤：
1. 用干布擦拭顶部视窗（透明罩）。
2. 检查是否有毛发、灰尘卡在旋转缝隙（可用镊子轻取）。
3. 不要拆卸激光塔（精密光学组件）。
注意事项：
- 激光塔被撞歪会导致建图歪斜、定位漂移，跌落后需检测。
- 禁止用水冲洗、禁止用酒精擦拭光学窗口。

【驱动轮与万向轮】
清洁频率：每周检查，每月清理。
操作步骤：
1. 翻转机器，检查左右驱动轮是否有毛发缠绕轮轴。
2. 用镊子清除缠绕物，手动转动确认顺畅。
3. 万向轮（前轮）可拔出清理内部毛发（多数可拆卸）。
4. 检查轮面橡胶是否磨损、开裂。
注意事项：
- 轮轴缠毛会导致"跛行""走偏""原地打转"。
- 轮面磨损严重会导致打滑、越障能力下降，需更换。

【充电极片】
清洁频率：每月（或出现充电异常时立即）。
操作步骤：
1. 用干布或橡皮擦擦拭机身底部极片与基站极片。
2. 去除氧化层和灰尘（氧化会导致接触不良、充电断续）。
3. 检查极片是否变形、弹簧是否失效。
注意事项：
- 禁止用砂纸打磨（会破坏镀层，加速氧化）。
- 极片发黑、烧蚀需更换（打火风险）。

【风道】
清洁频率：每季度。
操作步骤：
1. 取出尘盒、滤网。
2. 用手电照射进风口，检查是否有异物（纸片、毛发团）。
3. 用长柄软刷或吸尘器（反向）清理。
4. 检查尘盒接口密封圈是否完好。
注意事项：
- 风道堵塞会导致吸力下降、风机过载发热。
- 不要用尖锐工具捅（会划伤风道内壁）。

基站清洗盘：1—2年｜99元
水箱密封圈：1—2年｜15元

【年耗材成本估算】
轻度使用（每周3—4次，80㎡，无宠物）：约250—350元/年。
常规使用（每天1次，100㎡）：约350—500元/年。
高频使用（每天2次，120㎡+，养宠）：约550—750元/年。
（不含电池更换，电池按2—3年摊销约70—150元/年）

【延长耗材寿命的技巧】
1. 每周清理滤网可延长到3个月更换（不要等堵死）。
2. 边刷卷边用热水整形可多用1个月。
3. 拖布每次用完立即烘干，可避免发霉报废（寿命差1倍）。
4. 减少强力模式使用频率，降低刷体磨损。
5. 大促（618/双11）囤耗材，通常5折。
6. 地面先做"减法"（收杂物），减少刷体异常磨损。


=== 四、季节性保养 ===

【梅雨季 / 回南天（南方3—6月）】
1. 拖地水量调到最小，或改为"仅扫"。
2. 每次任务后必须开启拖布烘干（3小时），必要时连烘两次。
3. 每天检查基站底盘是否积水，及时擦干。
4. 尘袋受潮会结块，更换周期缩短至30—40天。
5. 基站不要贴地墙面放置（留5厘米通风）。
6. 可用除湿机把室内湿度控制在50%—60%。

【夏季（高温）】
1. 避免基站被阳光直射（电池高温衰减、外壳老化）。
2. 充电环境温度不超过35℃。
3. 拖地后通风，防止霉味。
4. 不要在地面温度过高时拖地（水分快速蒸发留痕）。

【冬季（低温）】
1. 0℃以下不要把机器存放在阳台、车库（电池损伤、水箱冻裂）。
2. 从室外搬入室内，回温2小时后再充电。
3. 地暖房间用小水量拖地，避开升温阶段。
4. 空气干燥静电大，每周用微湿布擦机身，减少灰尘吸附。
5. 长假外出前排空水箱、关闭进水阀（上下水机型）。

【装修/搬家后】
1. 装修期间不使用（粉尘会损坏风机）。
2. 开荒保洁完成、地面彻底清理后再启用。
3. 搬家后删除旧地图重新建图，重新配网。
4. 检查运输过程是否有磕碰（激光塔、水箱）。


=== 五、长期存放与重新启用 ===

【存放前（超过1个月不用）】
1. 执行一次完整清扫，清理尘盒、刷体、滤网。
2. 拖布清洗后彻底烘干，拆下单独存放。
3. 清空清水箱、污水箱，开盖晾干。
4. 基站清洗盘拆下洗净晾干。
5. 电池充至50%—70%（不要满电、不要亏电）。
6. 关机，装回防尘袋或纸箱，放在干燥通风处（5—35℃）。
7. 上下水机型：关闭进水阀，排空管路。

【存放期间】
1. 每2个月充电一次至50%—70%，防止电池过放损坏。
2. 检查是否有受潮、虫蛀（纸箱存放注意）。

【重新启用】
1. 检查机身、水箱、刷体是否有霉斑、变形。
2. 装回拖布、刷体、尘盒，确认卡扣到位。
3. 充满电（首次建议充满后再建图）。
4. 更新固件到最新版本。
5. 重新建图（环境可能已变化）。
6. 先跑一次"仅扫"，确认无异响、无卡困，再开启扫拖。
7. 上下水机型：先通水冲洗管路1分钟再使用。


=== 六、保养误区（高频错误） ===

【误区1】滤网洗完全干不干无所谓
错误。湿滤网会导致：灰尘粘结堵塞、霉味、风机进水损坏。必须阴干24小时，这是最容易被忽略也最伤机器的一步。

【误区2】用84消毒液/酒精擦拭机身
错误。84腐蚀金属件与橡胶密封，酒精会使塑料外壳发白、开裂，还会腐蚀传感器透明罩。机身清洁只用微湿布，消毒用专用消毒液。

【误区3】拖布不脏就不用洗
错误。拖布看起来干净，但纤维里已藏细菌和油脂，拖地等于"均匀涂抹"。必须每次任务后清洗+烘干，这是异味的根源。

【误区4】尘盒满了再倒更省事
错误。尘盒满会降低吸力、增加风机负荷、导致垃圾倒吸回风道。建议每次任务后倒，最多不超过3天。

【误区5】边刷卷边了还能用
错误。卷边后清扫半径变小，墙边漏扫，还会把垃圾推走而非聚拢。一对边刷39元，不值得将就。

【误区6】基站底盘不用管，反正会自动洗
错误。清洗盘是所有异味的源头，必须每1—2周拆洗、疏通排水孔。这是"拖布反复发臭"90%的原因。

【误区7】电池要每次用完再充，充满再拔
错误。锂电池无记忆效应，随用随充最好。长期满电存放或长期亏电存放都会加速衰减，最佳存放电量是50%—70%。

【误区8】用洗衣粉/洗洁精洗拖布和滤网
错误。残留的表面活性剂会在地面形成黏性膜（越拖越脏），还会堵塞滤网微孔。用中性洗衣液，且必须彻底漂净。

【误区9】机器不用就收起来，越少用越耐用
错误。长期不用会导致电池亏电、密封圈干裂、水泵干涩。建议每月通电运行一次。

【误区10】耗材提示到期就必须换
不完全对。提示是按累计工时估算，与实际磨损不完全一致。以实际状态判断（刷毛长度、拖布是否变硬、滤网透光性），提示仅作参考。
