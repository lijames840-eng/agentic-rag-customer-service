扫地机器人故障排除手册
文档用途：智扫通Agent 知识库 · 售后故障自诊断与排查指引
品牌对象：智扫（Zhisao）S1 / S2 / S3 Pro / X1
更新日期：2026-10
使用说明：每条故障含【现象】【原因】【排查步骤】【处理建议】【是否需报修】【适用机型】六个字段，可作为独立 chunk 检索。


=== 使用原则（客服应答前必读）===

1. 先确认基础条件：电源是否接通、水箱/尘盒是否安装到位、耗材是否到期、地面是否有明显障碍。约40%的"故障"属于基础条件不满足。
2. 排查顺序遵循"由外到内"：外观/耗材 → 传感器清洁 → 复位重启 → 报修。不要一上来就建议返修。
3. 涉及拆机、电路、电池的，一律引导报修，禁止指导用户自行拆解（影响保修且存在安全风险）。
4. 报修前建议用户准备：购买凭证、机器SN码（机身底部或包装盒）、故障视频/照片、故障发生时间与频次。


=== 一、开机与供电类（F001-F008）===

【F001】按开机键无任何反应
现象：长按电源键3秒，指示灯不亮、无提示音、机器不动。
原因：① 电池完全亏电；② 电源键卡死/进灰；③ 电池保护板进入休眠保护；④ 主板或电池故障。
排查步骤：
1. 将机器人放回基站充电30分钟后再试（长时间未使用会导致深度亏电）。
2. 检查充电极片是否有污垢、氧化，用干布擦拭。
3. 换一个墙插，确认基站通电（基站指示灯是否亮）。
4. 若仍无反应，长按电源键10秒强制复位后再按。
处理建议：深度亏电需充电1小时以上再判断；连续充电2小时仍无反应，判定为硬件故障。
是否需报修：是（若充电2小时仍无反应）。
适用机型：全系。

【F002】开机后立即自动关机
现象：按下开机键，亮灯并语音提示后3—5秒自动关机。
原因：① 电池电量过低（低于5%）；② 电池老化、内阻过大；③ 电源管理板保护；④ 主板异常。
排查步骤：
1. 放回基站充电2小时，观察APP电量是否上升。
2. 查看APP"电池健康"或续航表现（若续航已不足标称50%，电池老化）。
3. 尝试在基站上直接启动清扫，看是否能持续工作。
处理建议：电池使用超过2年且续航明显下降，建议更换电池模块。
是否需报修：是（电池更换或主板检测）。
适用机型：全系。

【F003】充电时基站指示灯不亮
现象：机器人放上基站，基站无灯、无充电提示音。
原因：① 插座无电/排插开关关闭；② 电源适配器损坏；③ 基站内部电源板故障；④ 电源线虚接。
排查步骤：
1. 换一个已知有电的墙插测试。
2. 检查电源线与基站接口是否插到底。
3. 用万用表测适配器输出（有经验用户），或换同规格适配器测试。
处理建议：确认插座正常后仍无电，多为适配器或基站电源板问题。
是否需报修：是。
适用机型：全系。

【F004】扫地机放在基站上但提示"未充电"
现象：机器人在基站上，APP显示电量不增加，或提示"未检测到充电"。
原因：① 充电极片脏污/氧化；② 机器人未完全坐到底；③ 基站极片变形、下压不到位；④ 充电模块故障。
排查步骤：
1. 用干布或橡皮擦清洁机身底部极片与基站极片（最常见原因）。
2. 把机器人往里推到底，听到提示音确认接触。
3. 检查基站极片是否被压塌、弹簧是否失效。
4. 清洁后仍不充电，尝试用独立充电座（S1/S2支持）测试。
处理建议：极片清洁是首选动作；若极片变形需更换基站配件。
是否需报修：视情况（极片变形/充电模块故障需报修）。
适用机型：全系。

【F005】电量显示异常（忽高忽低/一直100%）
现象：APP电量数字跳动，或长时间显示满电但很快就没电。
原因：① 电量计未校准；② 电池老化；③ 长期未完整充放电；④ 固件bug。
排查步骤：
1. 执行一次完整放电（跑到自动回充）→ 充满，重复2次校准电量计。
2. 观察续航是否与显示一致。
3. 检查是否刚升级固件（升级后需一次完整充放电）。
处理建议：校准2次仍异常，且续航明显缩短，判定电池衰减。
是否需报修：视情况（电池老化需更换）。
适用机型：全系。

【F006】机身发热明显（充电时/工作时）
现象：机身底部或电池仓位置发烫，手感明显偏热。
原因：① 充电时正常发热（锂电池充电会升温）；② 环境温度过高/阳光直射；③ 散热孔堵塞；④ 电池异常。
排查步骤：
1. 确认是否在充电中（充电时温热属正常，超过45℃需注意）。
2. 检查基站是否被阳光直射、是否贴墙过近。
3. 清理机身底部散热孔灰尘。
4. 若工作时也异常发烫并伴随续航骤降，停止使用。
处理建议：移至阴凉通风处充电；温度超过50℃或有异味立即停用。
是否需报修：是（异常发热且伴随异味/鼓包）。
适用机型：全系。

【F007】开机后语音提示"电量低，请充电"但刚充满
现象：满电状态下启动，立即提示低电量并回充。
原因：① 电池老化（虚电）；② 电量检测异常；③ 充电未真正完成（极片接触不良导致假满）。
排查步骤：
1. 检查充电极片清洁度，确认充电时长（S1约3.5小时、S2约4小时、S3 Pro约4.5小时、X1约5小时）。
2. APP查看充电曲线是否正常上升。
3. 执行一次完整放电再充满。
处理建议：以上无效则电池衰减，需更换。
是否需报修：是。
适用机型：全系。

【F008】机器人无法关机（长按无效）
现象：长按电源键10秒仍无法关机。
原因：① 系统卡死；② 按键故障；③ 主板异常。
排查步骤：
1. 长按电源键10—15秒强制断电。
2. 若无效，将机器人从基站移开，静置至电池耗尽自动关机。
3. 重新充电后观察是否恢复。
处理建议：频繁卡死需检查固件版本并升级。
是否需报修：是（反复出现）。
适用机型：全系。


=== 二、充电与回充类（F009-F016）===

【F009】清扫结束后找不到基站，到处乱走
现象：清扫完成后机器人绕圈、多次尝试后停在原地并提示"未找到基站"。
原因：① 基站前方有遮挡；② 基站被移动，地图坐标失效；③ 距离过远且中间有多个房间；④ 基站信号发射异常。
排查步骤：
1. 确认基站前方1.5米、左右0.5米无遮挡物。
2. 检查基站是否被挪动过（挪动后必须重新建图或更新基站位置）。
3. 把机器人搬到基站正前方1米内，按"回充"键测试。
4. 清洁基站上的回充信号窗（红外发射/接收口）。
处理建议：基站位置固定是回充稳定的前提，建议在基站底部做定位标记。
是否需报修：否（多数为摆放问题）。
适用机型：全系。

【F010】回充过程中反复"试探"、多次对不准
现象：到基站附近反复调整位置，迟迟对不上充电极片。
原因：① 极片脏污导致接触不良；② 地面湿滑（刚拖完地）；③ 基站倾斜/地面不平；④ 回充传感器脏污。
排查步骤：
1. 擦净极片和回充信号窗。
2. 检查基站是否水平（用水平尺或目测），地面不平需垫平。
3. 避免在拖地后立即回充（等地面干）。
4. 检查驱动轮是否有异物缠绕。
处理建议：基站必须放在硬质平整地面，不要放在地毯或软垫上。
是否需报修：否（多为环境/清洁问题）。
适用机型：全系。

【F011】充不满电（停在80%—90%）
现象：充电数小时，电量停在80%—90%不再上升。
原因：① 电池保护策略（高温/低温限充）；② 电池老化；③ 充电模块限流；④ 长期插电导致电量计偏差。
排查步骤：
1. 确认环境温度（低于5℃或高于40℃会限充）。
2. 移开基站附近的发热源。
3. 断开充电、放电至20%后再充。
4. 观察是否稳定停在某个百分比（老化特征）。
处理建议：低温环境限充属正常保护；常温下长期充不满需检测电池。
是否需报修：视情况。
适用机型：全系。

【F012】充电时断时续（反复启停）
现象：充电指示灯闪烁，APP电量反复跳动。
原因：① 极片接触不良（最常见）；② 电源适配器输出不稳；③ 基站电源板故障；④ 电池保护板异常。
排查步骤：
1. 清洁极片、确认机器人坐到底。
2. 换插座，排除电压不稳。
3. 观察是否在特定电量区间发生（如80%以上）。
处理建议：优先处理接触问题，其次检测适配器。
是否需报修：是（清洁无效时）。
适用机型：全系。

【F013】基站充电时发出"滋滋"声
现象：充电中基站有轻微电流声或"滋滋"异响。
原因：① 变压器正常工作声（轻微、稳定）；② 适配器老化；③ 极片接触不良打火；④ 内部元件松动。
排查步骤：
1. 判断声音是否稳定轻微（正常）还是断续尖锐（异常）。
2. 检查极片是否有发黑、烧蚀痕迹（打火迹象）。
3. 触摸适配器是否异常发烫。
处理建议：轻微稳定电流声属正常；有焦味、发黑、异常发烫立即停用。
是否需报修：是（打火/焦味）。
适用机型：全系。

【F014】电池鼓包
现象：机身底部电池仓凸起，底盖闭合不严。
原因：① 电芯老化产气；② 长期高温环境；③ 过充/过放；④ 非原装电池。
排查步骤：
1. 立即停止使用和充电。
2. 不要挤压、穿刺、拆解。
3. 将机器移至通风、远离易燃物的地方。
4. 联系售后处理（属有害垃圾，不可随意丢弃）。
处理建议：鼓包电池存在起火风险，必须更换，禁止继续使用。
是否需报修：是（紧急）。
适用机型：全系。

【F015】电量低于20%不回充，继续工作到停机
现象：电量报警后仍继续清扫，直到彻底停机在房间中央。
原因：① 回充路径被阻断（门关闭、障碍物）；② 找不到基站；③ 设置中关闭了自动回充（少见）；④ 定位异常。
排查步骤：
1. 检查清扫期间是否有门被关上。
2. 确认基站位置未被移动。
3. 查看APP清扫记录中的中断原因。
处理建议：让机器人记住"清扫时保持通路"，或分房间执行任务。
是否需报修：否。
适用机型：全系。

【F016】充电座/基站被撞移位
现象：机器人回充时把基站撞得偏移，之后定位混乱。
原因：① 基站未固定（地面滑、仅靠自重）；② 回充速度过快；③ 地面倾斜。
排查步骤：
1. 基站底部贴防滑垫或使用官方固定贴。
2. 基站靠墙放置，减少被推挤空间。
3. 移位后重新建图（或APP更新基站位置）。
处理建议：基站位置变动会直接影响地图坐标系，务必固定。
是否需报修：否。
适用机型：全系。


=== 三、行走与卡困类（F017-F026）===

【F017】机器人频繁卡在家具下方/缝隙
现象：反复卡在同一位置，提示"机器被卡住，请移至空旷处"。
原因：① 家具底部净空略高于机身，进入后无法退出；② 椅子横撑、落地灯底座；③ 窗帘/床裙下摆；④ 窄缝宽度在35—40厘米之间（进得去出不来）。
排查步骤：
1. 定位卡困点（看APP轨迹或现场），测量该处净空高度与宽度。
2. 净空低于11厘米的区域设禁区。
3. 收起床裙、窗帘下摆（可用夹子固定）。
4. 椅腿横撑处贴防撞条或设禁区。
处理建议：卡困点90%可通过"设禁区+整理"解决，不要指望算法完全规避。
是否需报修：否。
适用机型：全系。

【F018】原地打转、不前进
现象：两个驱动轮反向转动，机器人在原地转圈。
原因：① 一侧驱动轮被异物卡住；② 轮子悬空（压在门槛/地毯边缘）；③ 驱动轮电机故障；④ 定位丢失后原地搜索。
排查步骤：
1. 翻转机器，检查左右驱动轮是否有毛发、线绳缠绕。
2. 清理轮轴异物，手动转动确认顺畅。
3. 把机器放到平整地面重新启动。
4. 观察是否只在特定地面发生（打滑/悬空）。
处理建议：轮子缠绕是最常见原因，清理后即可恢复。
是否需报修：是（清理后仍单侧不转，电机故障）。
适用机型：全系。

【F019】机器人"跛行"（一侧轮子不转/异响）
现象：走直线时明显偏斜，一侧轮子不转或有"咔哒"声。
原因：① 轮轴缠绕毛发；② 轮子齿轮磨损/断齿；③ 电机故障；④ 轮子脱出。
排查步骤：
1. 拆下驱动轮（部分机型可拆），清除缠绕物。
2. 手动转动听是否有异响、是否卡顿。
3. 检查轮子是否装到位（弹簧卡扣）。
处理建议：齿轮断齿需更换驱动轮模块。
是否需报修：是（齿轮/电机故障）。
适用机型：全系。

【F020】过不去门槛/地毯边
现象：在门槛前反复尝试、后退再冲，最终放弃或报错。
原因：① 门槛高于越障能力（S1/S2/S3 Pro为2.0厘米，X1为2.2厘米）；② 门槛表面光滑打滑；③ 轮子沾水打滑；④ 地毯边缘卷起。
排查步骤：
1. 实测门槛高度（用尺量，不要目测）。
2. 超过2厘米的加装坡道条（橡胶斜坡）。
3. 擦干轮子和门槛（刚拖完地时尤其明显）。
4. 地毯边缘用双面胶压平。
处理建议：物理改造（坡道条）比反复尝试更有效。
是否需报修：否。
适用机型：全系。

【F021】机器人在某处"犹豫不前"、反复试探
现象：面对某区域反复前进后退，不通过。
原因：① 透明/镜面物体（玻璃门、落地镜）被误判为悬崖或障碍；② 深色地面被误判为悬崖；③ 地面反光；④ 虚拟墙/禁区设置误挡。
排查步骤：
1. 检查APP地图该处是否设了禁区/虚拟墙。
2. 在玻璃门前贴磨砂膜或设禁区。
3. 深色地毯/深色瓷砖导致的误判，可关闭"悬崖检测增强"（部分机型支持）或在APP标记地面材质。
处理建议：光学误判属物理限制，优先用禁区规避。
是否需报修：否。
适用机型：全系。

【F022】悬崖传感器误报（在平地提示"请移至安全区域"）
现象：在平整地面上突然停止并提示悬崖/请移至安全区域。
原因：① 悬崖传感器窗口脏污；② 深色/反光地面误判；③ 传感器被遮挡（贴膜未撕）；④ 传感器故障。
排查步骤：
1. 翻转机器，用干布擦拭底部4—6个悬崖传感器窗口（黑色半透明小窗）。
2. 确认底部保护膜已全部撕除。
3. 换到浅色地面测试是否正常。
4. 若只在特定区域误报，对该区域设禁区。
处理建议：清洁传感器可解决大部分误报。
是否需报修：是（清洁后全地面误报）。
适用机型：全系。

【F023】机器人推着东西走（拖鞋、纸箱、玩具）
现象：边刷把轻物推着走，或机身顶着小物件移动。
原因：① 物件过轻（拖鞋、纸杯）；② AI避障未识别（非训练物体）；③ 避障灵敏度设置过低。
排查步骤：
1. APP中把"避障灵敏度"调高（S3 Pro/X1支持）。
2. 清扫前收起轻质物品（最有效）。
3. 该区域设禁区。
处理建议：不要依赖避障识别所有物体，地面整理仍是前提。
是否需报修：否。
适用机型：全系（避障调节仅S3 Pro/X1）。

【F024】机器人被电线/窗帘缠绕
现象：停止工作，提示"请清理缠绕物"，刷体被线缠死。
原因：① 地面电线未收纳；② 窗帘下摆过长；③ 地毯流苏；④ 充电线垂地。
排查步骤：
1. 断电后剪断缠绕物（不要硬拽，避免损伤刷轴）。
2. 用理线器固定电线，或设禁区。
3. 窗帘下摆离地至少2厘米。
处理建议：缠绕后必须检查刷轴是否变形，变形需更换。
是否需报修：视情况（刷轴/电机损伤需报修）。
适用机型：全系。

【F025】机器人在基站附近"打转"无法进入
现象：到了基站前面，反复调整角度进不去。
原因：① 基站前方空间不足1.5米；② 基站左右有障碍物；③ 回充信号受干扰（旁边有镜面、金属）；④ 基站放置倾斜。
排查步骤：
1. 清空基站前方1.5米×1.5米区域。
2. 基站左右各留5厘米以上。
3. 移开基站旁的镜面/大面积金属物。
4. 确认基站放在硬质平整地面。
处理建议：基站摆放位置是回充成功率的决定性因素。
是否需报修：否。
适用机型：全系。

【F026】机器人从高处跌落
现象：从台阶/楼梯摔落，机身外壳破损或功能异常。
原因：① 悬崖传感器脏污/故障；② 深色或镜面地面误判；③ 楼梯口未设虚拟墙。
排查步骤：
1. 立即断电，检查外壳、轮子、激光塔是否变形。
2. 检查悬崖传感器窗口是否被撞裂。
3. 开机测试各项功能（行走、吸力、回充）。
4. 楼梯口必须设虚拟墙+物理挡板。
处理建议：跌落可能导致激光塔偏移（建图歪斜）、主板虚焊，建议全面检测。
是否需报修：是（跌落后建议检测）。
适用机型：全系。


=== 四、清扫与吸力类（F027-F036）===

【F027】吸力明显变小
现象：清扫后地面仍有明显灰尘、碎屑吸不进去。
原因：① 尘盒满/尘袋满；② 滤网堵塞（最常见）；③ 主刷缠绕毛发；④ 进风口/风道堵塞；⑤ 风机老化；⑥ 密封条老化漏气。
排查步骤：
1. 清空尘盒/更换尘袋。
2. 取出滤网，检查是否积灰板结；水洗后必须晾干24小时。
3. 翻转机器，清理主刷缠绕物和进风口。
4. 检查尘盒密封圈是否变形、缺失。
5. 用手贴近出风口感受风量（对比新机明显偏弱，可能风机问题）。
处理建议：按"尘盒→滤网→刷体→风道→密封"顺序排查，80%在滤网和刷体。
是否需报修：是（清洁后吸力仍明显偏弱）。
适用机型：全系。

【F028】清扫时灰尘从出风口吹出
现象：机器人身后有扬尘，或出风口有灰迹。
原因：① 滤网破损/未干透/未装到位；② 尘盒密封圈老化；③ 尘盒未卡紧；④ 使用了非原装劣质滤网。
排查步骤：
1. 取出滤网对着光看是否破损、透光异常。
2. 确认滤网完全晾干（湿滤网会导致灰尘粘结、透气差）。
3. 检查尘盒密封圈是否变形、有无异物。
4. 重新安装尘盒，确认卡扣到位。
处理建议：滤网建议2个月更换，破损立即换。
是否需报修：否。
适用机型：全系。

【F029】主刷不转/转动无力
现象：滚刷不转，或转动缓慢、有异响。
原因：① 毛发缠绕卡死（最常见）；② 刷体轴承进灰/磨损；③ 传动皮带断裂；④ 电机过载保护。
排查步骤：
1. 取下主刷，用清理刀割断缠绕毛发（两端轴承处重点清理）。
2. 手动转动刷体，感受是否顺畅。
3. 清理后重启，观察是否恢复。
4. 若听到电机转但刷体不转，可能是皮带/齿轮问题。
处理建议：每周清理一次主刷可避免90%的此类故障。
是否需报修：是（清理后仍不转）。
适用机型：全系。

【F030】边刷不转/边刷脱落
现象：一侧边刷停转或掉落。
原因：① 边刷被毛发缠死；② 边刷卡扣磨损/断裂；③ 边刷电机故障；④ 安装未到位。
排查步骤：
1. 取下边刷清理缠绕物。
2. 检查卡扣是否完好，重新按压到位（听到"咔"声）。
3. 交换左右边刷测试（判断是刷体还是电机问题）。
4. 若换新边刷仍不转，判定电机故障。
处理建议：边刷为耗材，2—3个月更换；卡扣松动建议直接换新。
是否需报修：是（电机故障）。
适用机型：全系。

【F031】清扫有遗漏（地图显示扫过但实际没扫）
现象：某些区域始终未清洁，轨迹显示已覆盖。
原因：① 家具遮挡导致绕行；② 门槛阻挡；③ 地图分区错误；④ 覆盖率算法误差；⑤ 该区域被设为禁区（用户遗忘）。
排查步骤：
1. 查看APP禁区设置，是否有误设。
2. 检查该区域是否有物理阻挡。
3. 用"指哪扫哪"测试该点是否能到达。
4. 重新建图并修正分区边界。
处理建议：单次覆盖率约95%，边角漏扫属正常，定期人工补扫。
是否需报修：否。
适用机型：全系。

【F032】清扫时反复经过同一区域
现象：在同一小块区域来回多次，效率低。
原因：① 定位漂移（地面反光、打滑）；② 地图与实际不符；③ 该区域有轻微障碍导致反复重试；④ 传感器脏污。
排查步骤：
1. 清洁激光塔（顶部视窗）和沿墙传感器。
2. 检查该区域是否有反光地面、镜面。
3. 重新建图。
4. 确认该区域无障碍物（低矮线缆、地毯边）。
处理建议：先清洁传感器+重建地图，多数可解决。
是否需报修：否。
适用机型：全系。

【F033】地面清扫后仍有毛发
现象：清扫后地面残留毛发、絮状物。
原因：① 主刷类型不适（胶毛一体易缠毛）；② 吸力档位过低；③ 尘盒已满；④ 边刷把毛发推到墙角未吸走。
排查步骤：
1. 切到标准/强力档测试。
2. 清空尘盒、清理主刷。
3. 检查边刷是否变形（卷边会把垃圾推走而非聚拢）。
4. 长发/养宠家庭建议换胶刷。
处理建议：毛发问题主要靠"刷体类型+高频清扫"，不是靠吸力。
是否需报修：否。
适用机型：全系。

【F034】大颗粒（猫砂、瓜子壳）吸不进去
现象：颗粒被弹开或卡在进风口。
原因：① 吸力档位低；② 进风口被毛发堵塞；③ 颗粒直径超过8毫米；④ 拖布打湿导致颗粒粘地。
排查步骤：
1. 切强力档，拆下拖布，执行"仅扫"。
2. 清理进风口和风道。
3. 大颗粒先用扫把处理，再让机器人收尾。
处理建议：直径大于8毫米的颗粒超出设计能力，属正常限制。
是否需报修：否。
适用机型：全系。

【F035】清扫后有异味（尘土味/霉味）
现象：出风口吹出的风有异味，或清扫后房间有土腥味。
原因：① 滤网长期未换/未干透发霉；② 尘盒内垃圾发酵；③ 尘袋长期未换；④ 主刷/边刷沾污；⑤ 风道积灰。
排查步骤：
1. 更换滤网（不要清洗后反复使用超过5次）。
2. 清空并擦洗尘盒，晾干。
3. 更换尘袋。
4. 用微湿布擦拭风道入口。
处理建议：异味根源多为"湿滤网"和"垃圾滞留"，按周期更换耗材即可。
是否需报修：否。
适用机型：全系。

【F036】清扫时机器突然停止（无报错）
现象：工作中途停止，无语音提示或提示含糊。
原因：① 电量耗尽；② 尘盒满触发保护；③ 卡困超时；④ 定时任务结束；⑤ 系统异常重启。
排查步骤：
1. 查看APP清扫记录的中断原因（最直接）。
2. 检查电量、尘盒、是否卡困。
3. 重启机器再试。
处理建议：偶发一次属正常（多为卡困重试失败）；频繁发生需看记录定位原因。
是否需报修：是（频繁无原因停机）。
适用机型：全系。


=== 五、拖地与基站类（F037-F050）===

【F037】拖地不出水
现象：拖布是干的，地面没有水痕。
原因：① 清水箱无水；② 水量设为0/仅扫模式；③ 出水孔堵塞（水垢）；④ 水箱未装到位；⑤ 水泵故障/气阻。
排查步骤：
1. 确认清水箱有水、水量档位不为0、任务模式含"拖地"。
2. 取出水箱，用针疏通出水孔，或用1:10白醋浸泡30分钟。
3. 重新安装水箱，确认推到底。
4. 贴耳听水泵是否有轻微工作声（无声音可能泵故障）。
处理建议：水垢堵塞在硬水地区高发，建议使用过滤水。
是否需报修：是（通孔后仍不出水）。
适用机型：S2/S3 Pro/X1。

【F038】拖地水量过大/地面有明显积水
现象：拖完地面湿滑，有明显水洼。
原因：① 水量档位过高；② 出水阀卡在常开位置；③ 拖布不吸水（老化/非原装）；④ 地面坡度导致积水。
排查步骤：
1. 降到小水量测试。
2. 更换新拖布测试（老化拖布吸水率下降）。
3. 检查是否只在坡道/低洼处积水（物理原因）。
4. 若小水量仍大量出水，可能出水阀故障。
处理建议：木地板务必用小水量；出现持续渗水立即停用。
是否需报修：是（阀门故障）。
适用机型：S2/S3 Pro/X1。

【F039】基站不洗拖布/洗拖布异常
现象：任务结束后基站未执行清洗，或清洗时无水/异响。
原因：① 清水箱缺水；② 清洗盘未装到位；③ 喷水孔堵塞；④ 清洗程序被关闭（设置问题）；⑤ 水泵故障。
排查步骤：
1. 检查清水箱水位、清洗盘是否卡到位。
2. APP中确认"自动洗拖布"已开启。
3. 清理清洗盘喷水孔（牙签疏通）。
4. 手动触发一次"洗拖布"观察水流。
处理建议：喷孔堵塞是最常见原因，建议每2周清理。
是否需报修：是（手动触发仍无水/泵异响）。
适用机型：S3 Pro/X1。

【F040】拖布烘不干/烘干后仍有潮气
现象：烘干程序结束，拖布仍潮湿、有异味。
原因：① 烘干时间设置过短；② 出风口被遮挡；③ 环境湿度极高（梅雨季）；④ 加热模块故障；⑤ 拖布过厚/非原装。
排查步骤：
1. 检查烘干时长设置（建议3小时）。
2. 确认基站周围通风、出风口无遮挡。
3. 更换原装拖布测试。
4. 手感受出风口是否有热风（无热风为加热模块故障）。
处理建议：梅雨季可连烘两次；长期烘不干需检测加热模块。
是否需报修：是（无热风）。
适用机型：S3 Pro/X1。

【F041】污水箱已满但提示不消失/无法排空
现象：倒空污水箱后仍提示"污水箱已满"。
原因：① 污水箱未装到位（浮子未复位）；② 浮子卡住；③ 液位传感器脏污；④ 排水口堵塞。
排查步骤：
1. 重新安装污水箱，确认卡扣到位。
2. 晃动污水箱听浮子是否活动（卡住可轻敲）。
3. 清洗污水箱内部和液位传感器窗口。
4. 检查箱盖密封圈是否变形。
处理建议：浮子卡住多为污垢粘连，温水浸泡清洗可解决。
是否需报修：是（反复出现）。
适用机型：S3 Pro/X1。

【F042】基站底盘积水/漏水
现象：基站底部有积水，或周围地面有水。
原因：① 清洗盘排水孔堵塞；② 污水箱过满；③ 清水箱密封圈老化；④ 补水接口漏水；⑤ 上下水管接头松动。
排查步骤：
1. 拆下清洗盘，疏通排水孔（毛发堵塞最常见）。
2. 倒空污水箱，检查箱盖是否盖紧。
3. 擦干后运行一次，观察渗水点。
4. 装上下水的检查进水/排水接头。
处理建议：清洗盘必须每1—2周拆洗，否则必然积水发臭。
是否需报修：是（箱体/接口渗漏）。
适用机型：S3 Pro/X1。

【F043】拖布安装不上/装不牢
现象：拖布无法卡入支架，或工作中脱落。
原因：① 拖布非原装（尺寸偏差）；② 卡扣/磁吸件损坏；③ 支架变形；④ 安装方向错误。
排查步骤：
1. 按说明书确认正反面和方向。
2. 检查卡扣是否断裂、磁铁是否脱落。
3. 换一对新拖布测试（判断是拖布还是支架问题）。
处理建议：非原装拖布尺寸偏差是主因，建议用原装配件。
是否需报修：是（支架/卡扣损坏）。
适用机型：S2/S3 Pro/X1。

【F044】拖地后地面有轮印/拖布印
现象：地面出现两条轮子压痕或拖布拖痕。
原因：① 地面未干就再次碾压；② 轮子沾污；③ 拖布过脏；④ 水量不均。
排查步骤：
1. 清洁驱动轮表面。
2. 更换/清洗拖布。
3. 降水量，避免大面积积水后二次碾压。
处理建议：拖地后避免立即二次清扫同一区域。
是否需报修：否。
适用机型：S2/S3 Pro/X1。

【F045】水箱加水后漏水（机身）
现象：装好水箱后，机身底部渗水。
原因：① 水箱密封圈缺失/老化；② 水箱开裂；③ 出水口硅胶阀破损；④ 安装不到位。
排查步骤：
1. 取出水箱，检查密封圈是否在位、有无变形。
2. 装水后单独静置观察是否从箱体渗漏。
3. 检查出水口阀门是否闭合。
处理建议：密封圈可单独购买（约15元）；箱体开裂需换水箱。
是否需报修：视情况。
适用机型：S2/S3 Pro/X1。

【F046】基站自动集尘失败
现象：任务结束不集尘，或集尘时吸力弱、垃圾未进入尘袋。
原因：① 尘袋已满/未安装；② 尘盒接口未对准；③ 集尘风道堵塞；④ 尘袋安装方向错误；⑤ 集尘风机故障。
排查步骤：
1. 检查尘袋是否装满、是否安装到位（袋口卡入）。
2. 检查尘盒出尘口与基站接口是否对齐（机器人是否完全坐到底）。
3. 清理风道内的毛发团。
4. 手动触发一次集尘，听风机声音是否正常。
处理建议：尘袋45—60天更换，不要等完全装满（影响吸力）。
是否需报修：是（风机无吸力）。
适用机型：S2/S3 Pro/X1。

【F047】基站报"清洗盘异常"
现象：APP/语音提示清洗盘异常，无法洗拖布。
原因：① 清洗盘未装到位；② 排水孔堵塞导致水位异常；③ 清洗盘传感器脏污；④ 清洗盘变形。
排查步骤：
1. 取出清洗盘重新安装，确认卡到位。
2. 疏通排水孔、清洁传感器触点。
3. 检查盘体是否变形（可放平观察）。
处理建议：清洗盘属半耗材（1—2年），变形建议更换。
是否需报修：视情况。
适用机型：S3 Pro/X1。

【F048】上下水模块"进水异常"
现象：提示进水异常，基站不补水。
原因：① 进水阀未打开；② 水压不足（低于0.1MPa）；③ 进水滤网堵塞；④ 管路打折；⑤ 电磁阀故障。
排查步骤：
1. 确认进水阀门全开。
2. 检查其他水龙头水压是否正常。
3. 拆下进水接头，清洗滤网。
4. 检查软管是否被压折。
处理建议：老小区水压低建议加装增压泵或改用水箱模式。
是否需报修：是（水压正常、滤网清洁仍报错）。
适用机型：X1（选配上下水）。

【F049】上下水模块"排水异常"
现象：污水排不出，基站积水或报警。
原因：① 排水管打折/堵塞；② 地漏堵塞；③ 排水泵故障；④ 排水高度超过扬程（约1米）。
排查步骤：
1. 检查排水管走向，消除死弯。
2. 拆下管子检查是否堵塞（毛发、油垢）。
3. 确认排水口低于或接近基站（不超过扬程）。
4. 手动触发排水，听泵是否工作。
处理建议：排水管建议每3个月冲洗一次。
是否需报修：是（管路通畅仍不排水）。
适用机型：X1（选配上下水）。

【F050】拖地后地毯被打湿
现象：地毯边缘或整块被拖湿。
原因：① 地毯识别失败（深色/长毛/过薄）；② 拖布抬升未执行；③ 未设禁拖区；④ 地毯厚度超识别范围。
排查步骤：
1. APP中把该地毯区域设为"禁拖区"（最可靠）。
2. 检查拖布抬升功能是否正常（可在APP手动测试）。
3. 清洁机身底部的地毯识别传感器。
4. 长毛地毯直接设禁区。
处理建议：不要完全依赖自动识别，重要地毯一律手动设禁拖区。
是否需报修：否（多为识别限制）。
适用机型：S2/S3 Pro/X1。


=== 六、导航与建图类（F051-F058）===

【F051】建图失败/建图不完整
现象：建图结束后地图缺房间、形状错乱。
原因：① 有房门关闭；② 地面杂物多导致绕行；③ 光线不足（视觉导航）；④ 激光塔被遮挡/脏污；⑤ 中途被抱动。
排查步骤：
1. 打开所有房门，收起地面杂物。
2. 清洁激光塔顶部视窗（不要用酒精，用干布）。
3. 开灯（视觉避障机型）。
4. 重新执行"快速建图"，全程不要移动机器。
处理建议：首次建图建议人在场跟随，及时清障。
是否需报修：否。
适用机型：全系。

【F052】地图丢失/每次启动都要重建
现象：APP地图空白，或每次启动提示"未找到地图"。
原因：① 恢复出厂/固件升级；② 基站位置变动；③ 存储异常；④ 账号切换。
排查步骤：
1. APP"地图管理"中查看是否有历史地图可恢复。
2. 确认基站未被移动（移动后坐标系失效）。
3. 重启机器和APP。
4. 无法恢复则重建（建图约10—20分钟）。
处理建议：地图丢失不影响清扫，只是失去分区/禁区设置。
是否需报修：是（频繁丢失且基站未动）。
适用机型：全系。

【F053】定位失败/机器人"迷路"
现象：提示"定位失败，请检查基站"，路线混乱。
原因：① 基站被移动；② 环境变化过大（家具大搬动）；③ 激光被遮挡（窗帘、桌布垂下）；④ 地面反光/镜面；⑤ 传感器脏污。
排查步骤：
1. 清洁激光塔和沿墙传感器。
2. 把机器放回基站，APP执行"重新定位"。
3. 检查基站周围是否有遮挡（窗帘、柜门）。
4. 移开镜面/反光物体或设禁区。
5. 仍失败则删除地图重建。
处理建议：定位失败多为"基站移位"和"传感器脏污"。
是否需报修：否（多数为环境因素）。
适用机型：全系。

【F054】地图与实际不符（房间形状错乱、墙线歪斜）
现象：APP地图上墙体弯曲、房间重叠。
原因：① 建图时激光被遮挡；② 建图时机器被搬动；③ 镜面反射导致重复建图；④ 基站倾斜。
排查步骤：
1. 删除地图，重新建图。
2. 建图时移开镜面、玻璃、金属反光物。
3. 确认基站水平。
4. 建图全程不移动机器、不抱起。
处理建议：镜面是地图错乱的高发原因（会"复制"出一个假房间）。
是否需报修：否。
适用机型：全系。

【F055】房间分错（厨房和餐厅连成一块）
现象：开放式区域被识别为一个房间，无法单独清扫。
原因：① 无实体墙分隔，算法按开口判断；② 门洞过宽；③ 建图时门开着。
排查步骤：
1. APP"地图编辑"中手动拆分房间（画分割线）。
2. 给拆分后的区域分别命名。
3. 保存后可单独设定清扫参数。
处理建议：开放式户型建议建图后手动分区一次，之后长期有效。
是否需报修：否。
适用机型：S2/S3 Pro/X1。

【F056】多层地图无法自动切换
现象：搬到二楼后仍按一楼地图工作，或提示定位失败。
原因：① 该层未建图；② 楼层相似度高导致误识别；③ 地图数量已达上限；④ 未在APP选择楼层。
排查步骤：
1. 确认该层已单独建图（S2以上支持多层）。
2. APP中手动选择对应楼层地图。
3. 删除不用的旧地图（上限3—5张）。
4. 若两层布局几乎相同，建议每层各配充电座以辅助识别。
处理建议：多层户型建议每层配基站，体验最稳。
是否需报修：否。
适用机型：S2/S3 Pro/X1。

【F057】禁区/虚拟墙不生效
现象：设置了禁区，机器人仍进入。
原因：① 设置后未保存/未同步；② 地图被重建（禁区丢失）；③ 定位漂移导致坐标偏移；④ 禁区过窄（小于机身宽度）。
排查步骤：
1. 确认禁区已保存并同步到设备（APP显示同步状态）。
2. 检查地图是否被重建过（禁区需重设）。
3. 适当扩大禁区范围（边缘留10厘米余量）。
4. 重启设备后再测试。
处理建议：禁区依赖定位精度，定位漂移时会失效，重要区域建议加物理阻挡。
是否需报修：否。
适用机型：全系（S1支持基础禁区）。

【F058】沿墙/边角清扫不贴边
现象：墙边留有2—4厘米未清扫带。
原因：① 圆形机身物理限制；② 边刷变形/卷边；③ 沿墙传感器脏污导致提前转向。
排查步骤：
1. 更换边刷（变形边刷聚拢能力下降）。
2. 清洁侧前方沿墙传感器。
3. 使用"沿边清扫"模式单独跑一遍。
4. X1可开启机械臂贴边功能。
处理建议：2—4厘米盲区属行业普遍现象，靠边刷+人工定期补扫解决。
是否需报修：否。
适用机型：全系。


=== 七、联网与APP类（F059-F065）===

【F059】配网失败（一直停留在连接中）
现象：APP提示"配网失败"或进度卡在50%。
原因：① 连接了5GHz网络；② 路由器开启双频合一；③ 密码含特殊字符；④ AP隔离；⑤ 设备未进入配网模式。
排查步骤：
1. 确认手机连的是2.4GHz Wi-Fi（在路由器设置中单独开启2.4G）。
2. 关闭"双频合一"，让2.4G和5G分开显示。
3. 长按配网键5秒，指示灯快闪后再操作。
4. 关闭路由器"AP隔离/访客网络"。
5. 用手机热点（2.4G）测试，能连上说明是路由器设置问题。
处理建议：按上述顺序逐项排除，90%可解决。
是否需报修：否。
适用机型：全系。

【F060】设备经常离线
现象：APP显示"设备离线"，无法远程控制。
原因：① Wi-Fi信号弱；② 路由器重启后未重连；③ IP地址冲突；④ 路由器设置了设备限速/休眠；⑤ 云端服务异常。
排查步骤：
1. 查看路由器中设备信号强度，必要时加Mesh节点。
2. 重启路由器，等待5分钟看是否自动重连。
3. 在路由器中为设备分配固定IP（DHCP绑定）。
4. 关闭路由器的"Wi-Fi休眠/节能"功能。
处理建议：频繁离线优先排查Wi-Fi覆盖，而非设备本身。
是否需报修：视情况。
适用机型：全系。

【F061】APP无法添加设备（提示设备已被绑定）
现象：添加时提示"设备已被其他账号绑定"。
原因：① 前 owner 未解绑（二手设备）；② 自己用其他账号绑定过；③ 出厂状态未重置。
排查步骤：
1. 长按配网键10秒恢复出厂设置。
2. 用原账号登录解绑，或联系客服提供SN码强制解绑。
3. 二手设备务必让卖家先解绑。
处理建议：恢复出厂后仍提示被绑定，需客服协助。
是否需报修：否（联系客服解绑）。
适用机型：全系。

【F062】APP闪退/地图不显示
现象：打开APP崩溃，或地图区域空白。
原因：① APP版本过旧；② 系统权限被限制；③ 缓存异常；④ 服务器维护。
排查步骤：
1. 更新APP到最新版本。
2. 清除APP缓存或重装。
3. 检查手机网络、切换Wi-Fi/4G。
4. 查看官方公告是否有服务维护。
处理建议：重装APP不会丢失设备数据（数据在云端）。
是否需报修：否。
适用机型：全系。

【F063】定时任务不执行
现象：到了设定时间机器人没有启动。
原因：① 设备离线；② 电量低于设定阈值；③ 定时任务被关闭；④ 机器人在基站外/被卡住；⑤ 时区设置错误。
排查步骤：
1. 确认设备在线。
2. 检查任务开关是否开启、时间是否正确。
3. 确认机器人电量充足（建议在基站上）。
4. 检查是否与其他任务冲突。
处理建议：定时任务依赖联网，建议保持基站常在线。
是否需报修：否。
适用机型：全系。

【F064】语音控制无响应
现象：说"你好智扫"没有反应。
原因：① 环境噪音大；② 麦克风孔堵塞；③ 离线语音未开启；④ 唤醒词发音不清；⑤ 模块故障。
排查步骤：
1. 靠近机器（1米内）、降低环境噪音（关小吸力）再试。
2. 检查机身麦克风孔是否有灰尘/贴膜。
3. APP确认"离线语音"已开启。
4. 重启机器测试。
处理建议：吸力全开时识别率下降属正常，建议先暂停再下指令。
是否需报修：是（安静环境下仍无响应）。
适用机型：全系。

【F065】固件升级失败
现象：升级进度卡住、提示失败、升级后无法开机。
原因：① 升级中断电/断网；② 电量不足；③ 服务器异常；④ 升级包损坏。
排查步骤：
1. 确保电量50%以上、机器在基站上、网络稳定。
2. 重启机器后重新触发升级。
3. 连续失败可尝试切换网络（手机热点）。
4. 升级后无法开机，长按电源键15秒强制重启。
处理建议：升级期间严禁断电，否则可能需返厂刷机。
是否需报修：是（变砖）。
适用机型：全系。


=== 八、异响、异味与其他（F066-F072）===

【F066】行走时有"咔哒咔哒"异响
现象：行进中发出规律性咔哒声。
原因：① 轮子/主刷缠绕异物；② 刷体变形刮地；③ 驱动轮齿轮磨损；④ 机身内有异物（钉子、石块）。
排查步骤：
1. 翻转机器，检查主刷、边刷、驱动轮。
2. 清理刷体两端轴承处的毛发。
3. 检查刷体是否变形（平放观察）。
4. 摇动机身听是否有异物滚动声。
处理建议：清理后仍有异响，检查齿轮/轴承。
是否需报修：是（齿轮磨损）。
适用机型：全系。

【F067】风机异响（尖锐啸叫/嗡嗡声变大）
现象：吸力开启时噪音异常，音调变高。
原因：① 风道有异物（塑料片、纸片）；② 滤网安装不到位（漏气啸叫）；③ 风机轴承磨损；④ 尘盒密封不良。
排查步骤：
1. 取出滤网重新安装，确认卡到位。
2. 清理尘盒和风道入口。
3. 检查尘盒密封圈。
4. 若啸叫持续且吸力下降，可能风机故障。
处理建议：滤网未装到位是最常见的"啸叫"原因。
是否需报修：是（风机轴承磨损）。
适用机型：全系。

【F068】基站运行时震动/移位
现象：集尘或洗拖布时基站明显抖动、移动位置。
原因：① 地面不平；② 基站脚垫缺失；③ 集尘风机固定松动；④ 内部异物。
排查步骤：
1. 检查地面平整度、基站四脚是否着地。
2. 补装防滑脚垫。
3. 移除基站内异物。
处理建议：基站必须放在硬质平整地面，避免地毯/软垫。
是否需报修：是（内部固定松动）。
适用机型：S2/S3 Pro/X1。

【F069】机身外壳开裂/掉漆
现象：外壳出现裂纹、边角磨损。
原因：① 跌落/撞击；② 长期摩擦家具；③ 清洁剂腐蚀（用错清洁剂）。
排查步骤：
1. 确认是否跌落过（重点检查激光塔周围）。
2. 检查裂纹是否影响功能（进水/进灰风险）。
3. 用微湿布清洁，避免使用酒精、溶剂。
处理建议：裂纹会导致进灰、影响传感器，建议更换外壳。
是否需报修：是。
适用机型：全系。

【F070】机器人在充电座上"待机耗电"明显
现象：满电待机一天掉电10%以上。
原因：① 未真正接触充电极片；② 待机时保持联网/待命耗电（正常约1%—2%/天）；③ 电池老化。
排查步骤：
1. 确认充电接触良好（APP显示"充电中/已充满"）。
2. 观察是否频繁唤醒（APP日志）。
3. 对比新机耗电水平。
处理建议：待机每天掉电1%—2%属正常，超过5%需检查接触。
是否需报修：视情况。
适用机型：全系。

【F071】清扫时机器"漏扫"整个房间
现象：某个房间完全没进去。
原因：① 房门关闭；② 该房间被设为禁区；③ 门槛阻挡；④ 地图分区错误（被并入其他区域）；⑤ 电量不足跳过了远端房间。
排查步骤：
1. 检查门是否打开、禁区设置。
2. 用"指哪扫哪"测试能否进入。
3. 调整清扫顺序，把该房间排前面。
4. 修正地图分区。
处理建议：电量不足时把远端房间排前面，或分任务执行。
是否需报修：否。
适用机型：全系。

【F072】机器人清扫时"绕开"某块区域
现象：地图上该区域有明显未覆盖的空洞。
原因：① 该处有地毯/地垫（触发绕行或抬布）；② 地面反光误判为悬崖；③ 有低矮障碍（线缆）；④ 禁区边缘。
排查步骤：
1. 查看该处地面材质与障碍。
2. 检查是否被识别为地毯（可临时关闭地毯识别测试）。
3. 反光地面设"禁悬崖检测"或直接手动补扫。
处理建议：地毯绕行属正常逻辑（避免打湿），如需清扫可设"仅扫"。
是否需报修：否。
适用机型：全系。


=== 九、报错代码速查表 ===

说明：以下为智扫全系通用错误码。APP报错页会同时显示文字提示与处理建议，此表用于客服快速定位。

E01 悬崖传感器异常
含义：悬崖传感器被遮挡、脏污或故障。
处理：清洁底部4—6个传感器窗口；确认保护膜已撕除；仍报错则传感器故障，需报修。

E02 碰撞传感器异常
含义：前挡板卡住或传感器故障。
处理：轻按前挡板确认能回弹；清理挡板缝隙异物；仍报错需报修。

E03 风机异常
含义：风机堵转、过流或未连接。
处理：清理风道与尘盒入口；确认尘盒/滤网安装到位；重启；仍报错需报修。

E04 刷体缠绕/电机过载
含义：主刷或边刷被毛发、线绳缠死。
处理：取下刷体割断缠绕物，清理轴承；手动转动确认顺畅；重启。

E05 机器被卡住/轮子悬空
含义：驱动轮悬空、被卡或打滑。
处理：移至平整地面；清理轮轴异物；检查是否压在门槛/地毯边。

E06 尘盒未安装/尘袋异常
含义：尘盒未卡到位，或尘袋未装/已满。
处理：重新安装尘盒至卡扣到位；更换尘袋；检查尘盒密封圈。

E07 电量过低
含义：电量低于启动阈值。
处理：放回基站充电至30%以上再启动。

E08 充电异常/未检测到充电
含义：极片接触不良或充电模块故障。
处理：清洁极片；确认机器人坐到底；换插座测试；仍失败需报修。

E09 定位失败
含义：无法匹配地图或基站信号弱。
处理：清洁激光塔；把机器放回基站重新定位；检查基站是否移位；必要时重建地图。

E10 地图异常/地图丢失
含义：地图数据损坏或存储异常。
处理：尝试恢复地图；无法恢复则删除重建。

E11 清水箱缺水
含义：清水箱空或未装到位。
处理：加水至MAX线以下；重新安装水箱；检查浮子。

E12 污水箱已满
含义：污水箱满或浮子卡住。
处理：倒空并冲洗污水箱；确认安装到位；轻敲箱体使浮子复位。

E13 清洗盘异常/排水异常
含义：清洗盘未装好、排水孔堵塞。
处理：拆下清洗盘疏通排水孔；重新安装到位；清理传感器触点。

E14 拖布异常
含义：拖布未安装、脱落或支架卡死。
处理：重新安装拖布（确认方向）；清理支架缠绕物；更换变形拖布。

E15 进水异常（上下水）
含义：进水阀关闭、水压低或滤网堵塞。
处理：打开进水阀；清洗进水滤网；检查管路是否打折。

E16 排水异常（上下水）
含义：排水管堵塞、打折或泵故障。
处理：检查排水管走向；清理堵塞；确认排水高度不超过扬程。

E17 激光罩被遮挡/上盖未关
含义：激光塔被遮挡或上盖未扣紧。
处理：清理激光塔周围遮挡物；确认上盖卡扣到位。

E18 温度过高
含义：机身或电池温度过高，触发保护。
处理：停止使用，移至阴凉通风处降温30分钟；避免阳光直射基站。

E19 电池异常
含义：电池通讯异常、电压异常或鼓包。
处理：停止充电；检查电池是否鼓包；联系售后（禁止自行拆解）。

E20 传感器需清洁
含义：沿墙/回充/地毯识别传感器脏污。
处理：用干布擦拭机身侧面、底部及基站信号窗；重启设备。

【通用复位方法】（客服可优先指导）
1. 软件复位：APP"设置—设备维护—重启设备"。
2. 硬件复位：长按电源键10—15秒。
3. 恢复出厂：长按电源键+回充键（或配网键）10秒，听到提示音后松开。恢复出厂会清空地图和设置，操作前告知用户。
